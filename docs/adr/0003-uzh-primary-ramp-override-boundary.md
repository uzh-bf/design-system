# UZH theme ownership and primary-ramp overrides

Status: Accepted (2026-08-12)

The design system owns the `uzh` theme and its component-token graph. A consumer
may provide a design-approved replacement for the complete primary ramp
(`primary`, `80`, `60`, `40`, and `20`) through the documented extension
contract; the design system derives primary, focus-ring, and sidebar bridges
from that ramp. The override remains consumer-owned and does not create a
separate design-system theme or package export. Secondary, status, destructive,
font, and other UZH tokens stay fixed unless a later decision deliberately
expands the contract.

## Consequences

- A single primary colour is not a supported override because the intermediate
  states must be design-approved rather than generated by implementation code.
- Klicker may use an approved primary ramp while remaining a UZH-themed
  consumer; its actual colour values do not live in this repository.
- Changes to the base UZH tokens are design-system changes reviewed against all
  representative consumers, not application-local adjustments.
