{/* START README */}
<div className="prose prose-sm max-w-none">
The `Item` component is a flexible row primitive for lists, settings panels, and
selectable entries. It composes a leading media slot, a title/description
content area, and a trailing actions slot into a single aligned row.

Use this component when you need to:

- Render a list of files, members, settings, or notifications
- Show a leading icon or avatar next to a title and description
- Place actions (buttons, switches, chevrons) at the end of a row
- Group several rows with optional separators via `ItemGroup` and `ItemSeparator`

`Item` supports `variant` (`default`, `outline`, `muted`) and `size`
(`default`, `sm`). Set `asChild` to render the row as a link or button while
keeping the layout.
</div>
