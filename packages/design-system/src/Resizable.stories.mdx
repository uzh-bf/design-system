<div className="prose prose-sm max-w-none">
Both public entries export `ResizablePanelGroup`, `ResizablePanel` and
`ResizableHandle`. These wrap native Panels 4 `Group`, `Panel` and `Separator`
with the same contract and component implementation. Use either door, or mix their components in one
group, when you need adjustable split panes, dashboards, editors or sidebars.

Panels 4 interprets numeric panel sizes as pixels. Write percentage sizes as
strings, such as `defaultSize="30%"`. Group layouts and layout callbacks still
use numbers as percentages. Groups support horizontal and vertical orientation,
nested layouts, constraints, disabled controls, RTL, keyboard and pointer
resizing, and a native double-click reset.

The exported `useGroupRef`, `usePanelRef` and `useDefaultLayout` helpers expose
the native imperative and persistence APIs. Saved layouts are ID-keyed maps.
Native 4.14.8 provides a limited legacy-read fallback. The design system adds
no converter; use a new persistence ID unless application acceptance proves
reuse of existing storage.
</div>

Technical Overview: Both Resizable entry points use the official shadcn Radix Panels 4 recipe with one component identity
Dependencies: react-resizable-panels@4.14.8

Available Stories:

- Default: Nested horizontal and vertical panels through the root Resizable entry
- Compatibility: Group and panel refs, layout maps, payloads, bounds, collapse, persistence and interactions through the root entry
- NativeCompatibility: Percent and pixel sizing, mixed root/primitive components, callbacks, persistence and nesting through the primitive entry

Props (ResizablePanelGroup):

- orientation: "horizontal" | "vertical" - Layout direction; defaults to horizontal
- defaultLayout: Layout - Initial ID-to-percentage map
- onLayoutChange: (layout: Layout) => void - Called continuously while the layout changes
- onLayoutChanged: (layout: Layout, meta) => void - Called after a completed change; use for persistence
- groupRef: Ref<GroupImperativeHandle> - Native getLayout/setLayout API
- elementRef: Ref<HTMLDivElement> - DOM ref for the group
- disabled: boolean - Disable resizing for the group
- resizeTargetMinimumSize: { coarse: number; fine: number } - Minimum pointer target in pixels
- className: string - Additional CSS classes

Props (ResizablePanel):

- defaultSize: number | string - Initial pixel, percentage or CSS-unit size
- minSize / maxSize: number | string - Pixel, percentage or CSS-unit constraints
- collapsible: boolean - Allow the panel to collapse
- collapsedSize: number | string - Nonzero or zero collapsed size
- panelRef: Ref<PanelImperativeHandle> - Native collapse/expand/getSize/resize API
- elementRef: Ref<HTMLDivElement> - DOM ref for the panel
- onResize: (current, id, previous) => void - Receives PanelSize values and the stable panel ID
- disabled: boolean - Prevent direct and indirect panel resizing
- className: string - Applied to the panel's nested inner div

Props (ResizableHandle):

- className: string - Additional CSS classes
- withHandle: boolean - Show the visual grip
- disabled: boolean - Disable this separator
- disableDoubleClick: boolean - Disable native default-size reset
- elementRef: Ref<HTMLDivElement> - DOM ref for the separator
- children: ReactNode - Custom separator content

Size interpretation:

- defaultSize={120}, minSize={80}, maxSize={240} and panelRef.current?.resize(120) use pixels.
- defaultSize="30%" and resize("30%") use percentages of the group.
- Layout maps and onLayoutChange/onLayoutChanged values use numeric percentages.
- Strings with another CSS unit, such as "16rem", use that unit.

Usage Examples:

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel id="sidebar" defaultSize="30%" minSize="20%">
    <div className="flex h-full items-center justify-center p-6">Sidebar</div>
  </ResizablePanel>
  <ResizableHandle withHandle />
  <ResizablePanel id="content" defaultSize="70%">
    <div className="flex h-full items-center justify-center p-6">Content</div>
  </ResizablePanel>
</ResizablePanelGroup>

// A pixel-sized panel uses a number; a percentage uses a string.
<ResizablePanel defaultSize={240} minSize={160}>
  Navigation
</ResizablePanel>

// Imperative layout maps use percentages.
groupRef.current?.setLayout({ sidebar: 40, content: 60 })
panelRef.current?.resize(200) // pixels

// Persist each conditional panel set by its matching IDs.
const { defaultLayout, onLayoutChanged } = useDefaultLayout({
  id: 'editor-layout',
  panelIds,
  storage: ssrSafeStorage,
})

<ResizablePanelGroup
  defaultLayout={defaultLayout}
  onLayoutChanged={onLayoutChanged}
>
  {panels}
</ResizablePanelGroup>
```

Migration from v3:

- Replace direction with orientation and use percentage strings for numeric percentage defaults.
- Replace React refs with groupRef/panelRef; use elementRef for DOM access.
- Replace positional layout arrays with ID-keyed layout maps.
- Replace autoSaveId and onLayout with useDefaultLayout and onLayoutChanged.
- Replace onCollapse and onExpand with onResize or the native panel ref. There is no native drag lifecycle callback.
- Remove tagName, order, hitAreaMargins and keyboardResizeBy. Use native divs, stable IDs and group resizeTargetMinimumSize.
- Native double-click resets a neighboring panel with a default size; other panels rebalance. It can be disabled per separator.
- Panel className applies to an inner div. Groups set inline flex direction; separators expose their own axis through aria-orientation.

Related Components:

- Sidebar: For fixed navigation panels
- Tabs: For switching between content sections
- Card: For structured content within panels
- Sheet: For overlay panels

export const Compatibility = () => {
  const rootStoryStorage = useMemo(() => ({
    getItem: (name) => typeof window === 'undefined' ? null : window.localStorage.getItem('resizable-root-story:' + name),
    setItem: (name, value) => {
      if (typeof window !== 'undefined') window.localStorage.setItem('resizable-root-story:' + name, value)
    },
  }), [])
  const groupRef = useGroupRef()
  const panelRef = usePanelRef()
  const [layout, setLayout] = useState({})
  const [nestedLayout, setNestedLayout] = useState({})
  const [boundsLayout, setBoundsLayout] = useState({})
  const [disabledLayout, setDisabledLayout] = useState({})
  const [rtlLayout, setRtlLayout] = useState({})
  const [refLayout, setRefLayout] = useState(null)
  const [refPanel, setRefPanel] = useState(null)
  const [collapsed, setCollapsed] = useState(false)
  const [resizeEvents, setResizeEvents] = useState([])
  const persistence = useDefaultLayout({
    id: 'root-story-persistence',
    panelIds: ['root-story-left', 'root-story-right'],
    storage: rootStoryStorage,
  })

  const readPanel = () => {
    setRefPanel(panelRef.current?.getSize() ?? null)
    setCollapsed(panelRef.current?.isCollapsed() ?? false)
  }

  return (
    <div className="bg-background text-foreground flex max-w-5xl flex-col gap-4 [&_output]:min-w-0 [&_output]:break-all">
      <div className="prose prose-sm max-w-none dark:prose-invert">
        Compatibility through the root entry covers native percentage sizing,
        ID-keyed layouts, group and panel refs, onResize payloads, nonzero
        collapse, bounds, custom persistence and interactions.
      </div>
      <div className="flex flex-wrap items-center gap-2">
        <button
          type="button"
          data-test="root-read-refs"
          onClick={() => {
            setRefLayout(groupRef.current?.getLayout() ?? null)
            readPanel()
          }}
        >
          Read root refs
        </button>
        <button
          type="button"
          data-test="root-set-layout"
          onClick={() =>
            groupRef.current?.setLayout({
              'root-story-left': 40,
              'root-story-right': 60,
            })
          }
        >
          Set root layout
        </button>
        <button
          type="button"
          data-test="root-resize-pixels"
          onClick={() => {
            panelRef.current?.resize(96)
            readPanel()
          }}
        >
          Resize root panel to pixels
        </button>
        <button
          type="button"
          data-test="root-collapse"
          onClick={() => {
            panelRef.current?.collapse()
            readPanel()
          }}
        >
          Collapse root panel
        </button>
        <button
          type="button"
          data-test="root-expand"
          onClick={() => {
            panelRef.current?.expand()
            readPanel()
          }}
        >
          Expand root panel
        </button>
        <output data-test="root-layout-state">{JSON.stringify(layout)}</output>
        <output data-test="root-nested-layout-state">
          {JSON.stringify(nestedLayout)}
        </output>
        <output data-test="root-ref-layout">{JSON.stringify(refLayout)}</output>
        <output data-test="root-ref-panel">{JSON.stringify(refPanel)}</output>
        <output data-test="root-collapsed">{String(collapsed)}</output>
        <output data-test="root-resize-events">
          {JSON.stringify(resizeEvents)}
        </output>
      </div>

      <ResizablePanelGroup
        id="root-story-group"
        data-testid="root-story-group-testid"
        data-test="root-story-group-test"
        orientation="horizontal"
        groupRef={groupRef}
        defaultLayout={persistence.defaultLayout}
        onLayoutChange={setLayout}
        onLayoutChanged={persistence.onLayoutChanged}
        aria-label="Root native layout"
        style={{ height: 180 }}
      >
        <ResizablePanel
          id="root-story-left"
          data-testid="root-story-left-testid"
          data-test="root-story-left-test"
          panelRef={panelRef}
          defaultSize="30%"
          minSize={48}
          maxSize="80%"
          collapsible
          collapsedSize={32}
          onResize={(current, id, previous) => {
            setResizeEvents((events) =>
              [...events, { current, id, previous }].slice(-8)
            )
            readPanel()
          }}
        >
          <div className="h-full bg-muted/30" />
        </ResizablePanel>
        <ResizableHandle
          id="root-story-separator"
          data-testid="root-story-separator-testid"
          data-test="root-story-separator-test"
          aria-label="Resize root native panels"
        />
        <ResizablePanel
          id="root-story-right"
          defaultSize="70%"
          minSize="20%"
        >
          <ResizablePanelGroup
            id="root-nested-group"
            orientation="vertical"
            onLayoutChange={setNestedLayout}
            aria-label="Nested root native layout"
          >
            <ResizablePanel id="root-nested-top" defaultSize="60%">
              <div className="h-full bg-muted/20" />
            </ResizablePanel>
            <ResizableHandle aria-label="Resize nested root native panels" />
            <ResizablePanel id="root-nested-bottom" defaultSize="40%">
              <div className="h-full bg-muted/10" />
            </ResizablePanel>
          </ResizablePanelGroup>
        </ResizablePanel>
      </ResizablePanelGroup>

      <ResizablePanelGroup
        id="root-bounds-group"
        orientation="horizontal"
        onLayoutChange={setBoundsLayout}
        style={{ height: 120 }}
      >
        <ResizablePanel
          id="root-bounds-left"
          defaultSize="50%"
          minSize="20%"
          maxSize="80%"
        >
          <div className="h-full bg-muted/30" />
        </ResizablePanel>
        <ResizableHandle
          id="root-bounds-separator"
          aria-label="Resize bounded root panels"
        />
        <ResizablePanel
          id="root-bounds-right"
          defaultSize="50%"
          minSize="20%"
          maxSize="80%"
        >
          <div className="h-full bg-muted/10" />
        </ResizablePanel>
      </ResizablePanelGroup>
      <output data-test="root-bounds-layout-state">
        {JSON.stringify(boundsLayout)}
      </output>

      <ResizablePanelGroup
        id="root-disabled-group"
        orientation="horizontal"
        onLayoutChange={setDisabledLayout}
        style={{ height: 140 }}
      >
        <ResizablePanel id="root-disabled-left" defaultSize="50%">
          <div className="h-full bg-muted/30" />
        </ResizablePanel>
        <ResizableHandle
          id="root-disabled-separator"
          disabled
          aria-label="Disabled root native resize handle"
        />
        <ResizablePanel id="root-disabled-right" defaultSize="50%">
          <div className="h-full bg-muted/10" />
        </ResizablePanel>
      </ResizablePanelGroup>
      <output data-test="root-disabled-layout-state">
        {JSON.stringify(disabledLayout)}
      </output>

      <ResizablePanelGroup
        id="root-rtl-group"
        orientation="horizontal"
        dir="rtl"
        onLayoutChange={setRtlLayout}
        style={{ height: 140 }}
      >
        <ResizablePanel id="root-rtl-left" defaultSize="50%">
          <div className="h-full bg-muted/30" />
        </ResizablePanel>
        <ResizableHandle
          id="root-rtl-separator"
          aria-label="Resize RTL root native panels"
        />
        <ResizablePanel id="root-rtl-right" defaultSize="50%">
          <div className="h-full bg-muted/10" />
        </ResizablePanel>
      </ResizablePanelGroup>
      <output data-test="root-rtl-layout-state">
        {JSON.stringify(rtlLayout)}
      </output>
    </div>
  )
}
