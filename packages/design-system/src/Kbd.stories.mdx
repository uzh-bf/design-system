<div className="prose prose-sm max-w-none">
The `Kbd` component renders a keyboard key or shortcut in a compact, muted
"key cap" style. `KbdGroup` lays out several keys (and separators) inline for
multi-key shortcuts.

Use this component when you need to:

- Document a keyboard shortcut (e.g. ⌘ K) in help text, menus, or tooltips
- Show available hotkeys next to an action
- Render a single key reference inline with body text

`Kbd` adapts inside tooltips automatically, switching to a contrast-appropriate
style when nested in a tooltip surface.
