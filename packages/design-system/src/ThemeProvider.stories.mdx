import { ThemeProvider, useTheme } from './ThemeProvider'
import { Button } from './Button'

{/* START README */}
<div className="prose prose-sm max-w-none">
`ThemeProvider` gives an app a design-system theme. It writes `data-theme` to
`document.documentElement` from an effect and keeps it in sync, so every DS
component — including Radix overlays that portal to `document.body` — resolves
its tokens against one theme on the document root. The element it renders is
`display: contents` and carries no theme itself.

There are two themes: `neutral` (the default, de-branded shadcn look) and `uzh`
(University of Zürich brand — primary blue, Source Sans 3). Use it **controlled**
(pass `theme`) or **uncontrolled** (pass `defaultTheme`, then read/update via the
`useTheme()` hook).

Two consequences follow from writing the root. Server-rendered markup is
unthemed until the effect runs, so render `<html data-theme="uzh">` yourself for
the theme the app starts in — the provider then syncs and toggles it on the
client. And several mounted providers do not create separate theme regions: the
root holds whichever theme was written last. Put the `dark` class on the
document root as well, next to `data-theme`, not on the provider's container.
</div>

```tsx
</html>

// Client: the provider syncs and toggles the same attribute.
<ThemeProvider theme="uzh">
  <App />
</ThemeProvider>
```

Related Components:

- All DS components consume the theme set here.

Limitations:

- The theme is global. Mounting a second provider does not theme a subtree; the document root keeps the theme written last.
- Without `<html data-theme>` in the server-rendered markup, the first paint uses the `neutral` default.

{/* The theme is a single document-root attribute, so a story cannot show two
themes next to each other. This demo page is itself wrapped in a provider
(driven by the theme switcher in the top-right corner) — the story below reads
that ambient theme and shows components following it. */}

export const Default = () => {
  const Readout = () => {
    const { theme } = useTheme()
    return <span className="text-sm font-bold">active theme: {theme}</span>
  }
  return (
    <div className="flex flex-col items-start gap-2">
      <Readout />
      <Button primary>Primary</Button>
    </div>
  )
}

{/* Seeded from the ambient theme so the demo starts where the switcher left it;
an app-level provider would pass a literal `defaultTheme` instead. Toggling
rewrites the document root, so the whole page follows — including this page's
own chrome. */}

export const Uncontrolled = () => {
  const Inner = () => {
    const { theme, setTheme } = useTheme()
    return (
      <Button
        primary
        onClick={() => setTheme(theme === 'uzh' ? 'neutral' : 'uzh')}
      >
        Toggle theme (current: {theme})
      </Button>
    )
  }
  const { theme } = useTheme()
  return (
    <ThemeProvider defaultTheme={theme}>
      <Inner />
    </ThemeProvider>
  )
}
