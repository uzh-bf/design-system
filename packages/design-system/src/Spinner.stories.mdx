<div className="prose prose-sm max-w-none">
The `Spinner` component is a minimal, accessible loading indicator. It renders a
spinning icon with `role="status"` and an `aria-label`, so screen readers
announce the loading state without any extra markup.

Use this component when you need to:

- Indicate an in-progress action (saving, fetching, processing)
- Show a loading state inside buttons, inputs, or list items
- Fill a panel while its content is loading

The spinner inherits the current text color (`currentColor`) and is sized via
the `size-*` utilities, so it adapts to whatever context it is placed in.
</div>
