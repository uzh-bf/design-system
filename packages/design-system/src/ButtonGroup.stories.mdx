import { Button } from './Button'
import {
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from './ButtonGroup'

{/* START README */}
<div className="prose prose-sm max-w-none">
The `ButtonGroup` component joins related buttons (and inputs) into a single
segmented control. Adjacent children share borders and have their inner corners
squared off so they read as one connected unit.

Use this component when you need to:

- Offer a small set of mutually related actions (e.g. Prev / Next, view toggles)
- Build a segmented control or split button
- Attach a label or static text to an input via `ButtonGroupText`

`ButtonGroup` supports `orientation` (`horizontal`, `vertical`). Use
`ButtonGroupSeparator` to insert a divider and `ButtonGroupText` for inline
non-interactive labels.
</div>
{/* END README */}

Props (ButtonGroupText component):

Component Structure:

- ButtonGroup: The container (role="group", data-slot="button-group")

- ButtonGroupText: Inline non-interactive text/label segment

Usage Examples:

```tsx

</ButtonGroup>
```

Related Components:

- Button: The primary children of a ButtonGroup
- ToggleGroup: For exclusive/multiple selection state, not just joined actions
- InputGroup: For joining inputs with addons rather than buttons

export const Default = () => {
  return (
    <ButtonGroup>
      <Button>Prev</Button>
      <Button>Next</Button>
    </ButtonGroup>
  )
}

export const WithText = () => {
  return (
    <ButtonGroup>
      <ButtonGroupText>Sort</ButtonGroupText>
      <ButtonGroupSeparator />
      <Button>Newest</Button>
      <Button>Oldest</Button>
    </ButtonGroup>
  )
}
