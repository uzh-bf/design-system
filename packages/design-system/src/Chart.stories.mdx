<div className="prose prose-sm max-w-none">
The `Chart` exports are the design-system's [Recharts](https://recharts.org)
wrapper (the shadcn chart primitives). `ChartContainer` provides a responsive,
token-themed canvas; `ChartTooltip` / `ChartTooltipContent` and `ChartLegend` /
`ChartLegendContent` give consistent tooltips and legends.

You drive the colors through a `config` object keyed by data series. Each key
maps to a `label` and a `color`; the container emits CSS variables
(`--color-<key>`) you reference from the Recharts marks (e.g.
`fill="var(--color-desktop)"`). Point a series `color` at a **theme-reactive**
DS token, such as `var(--chart-1)`, and the chart recolors with the active
theme and dark mode. These examples mix each plot token with the foreground
to preserve visible boundaries; measure your own series against the background.
Avoid the static `--color-primary-*` ramp here: those resolve once at `:root`
(neutral) and do **not** follow `data-theme` when read as a raw `var()`.
</div>

Technical Overview: Recharts wrapper. ChartContainer takes a `config` (series → label+color), emits `--color-<key>` CSS vars, and renders a responsive container. ChartTooltipContent / ChartLegendContent are themed tooltip/legend renderers. ChartContainer defaults initialDimension to 320×200 and accepts a caller override.
Dependencies: recharts

Available Stories:

- Default: representative bar chart, retaining the established story id
- Area: responsive two-series area chart
- Line: responsive line chart with a textual legend
- Pie: responsive segmented chart with zero and null values
- Radar: responsive radar chart
- Radial: responsive radial bar chart
- TooltipStates: default index, controlled active state, zero/null formatting, show/hide and resizing

Exports:

- ChartContainer - Responsive themed canvas; requires a `config` prop
- ChartTooltip / ChartTooltipContent - Recharts tooltip + themed content
- ChartLegend / ChartLegendContent - Recharts legend + themed content
- ChartStyle - Injects the per-series CSS color variables

Usage Examples:

```tsx
const config = {
  desktop: { label: 'Desktop', color: 'var(--chart-1)' },
}

<ChartContainer
  config={config}
  initialDimension={{ width: 320, height: 200 }}
  className="min-h-80 w-full max-w-3xl"
>
  <BarChart data={data}>
    <Bar dataKey="desktop" fill="var(--color-desktop)" />
  </BarChart>
</ChartContainer>
```

Related Components:

- Card: a common container for charts

export const TooltipStates = () => {
  const [tooltipVisible, setTooltipVisible] = React.useState(true)
  const [draftVisible, setDraftVisible] = React.useState(true)
  const [narrow, setNarrow] = React.useState(false)

  return (
    <ChartFrame
      title="Tooltip and interaction states"
      summary="The initial tooltip uses index zero, omits the null draft value, and preserves the formatter's zero output. The controls update active state, series geometry and responsive width."
      testId="chart-tooltip-states"
    >
      <div className="mb-4 flex flex-wrap gap-2">
        <button
          type="button"
          className="border-border bg-background hover:bg-muted rounded-md border px-3 py-1.5 text-sm font-medium"
          aria-pressed={tooltipVisible}
          data-test="chart-tooltip-toggle"
          onClick={() => setTooltipVisible((visible) => !visible)}
        >
          {tooltipVisible ? 'Hide tooltip' : 'Show tooltip'}
        </button>
        <button
          type="button"
          className="border-border bg-background hover:bg-muted rounded-md border px-3 py-1.5 text-sm font-medium"
          aria-pressed={draftVisible}
          data-test="chart-series-toggle"
          onClick={() => setDraftVisible((visible) => !visible)}
        >
          {draftVisible ? 'Hide draft series' : 'Show draft series'}
        </button>
        <button
          type="button"
          className="border-border bg-background hover:bg-muted rounded-md border px-3 py-1.5 text-sm font-medium"
          aria-pressed={narrow}
          data-test="chart-width-toggle"
          onClick={() => setNarrow((isNarrow) => !isNarrow)}
        >
          {narrow ? 'Widen chart' : 'Narrow chart'}
        </button>
      </div>
      <div
        className="max-w-full"
        data-test="chart-resize-frame"
        style={{ width: narrow ? '18rem' : '36rem' }}
      >
        <ChartContainer
          config={trendConfig}
          initialDimension={{ width: 360, height: 240 }}
          className="aspect-auto h-80 w-full"
          data-test="chart-tooltip-states"
          role="group"
          aria-label="Controlled bar chart for tooltip and resize states"
        >
          <BarChart data={tooltipData} margin={{ top: 12, right: 8, left: 8 }}>
            <CartesianGrid vertical={false} />
            <XAxis dataKey="month" tickLine={false} axisLine={false} />
            <ChartTooltip
              active={tooltipVisible}
              defaultIndex={0}
              filterNull={false}
              content={
                <ChartTooltipContent
                  formatter={(value) => (
                    <span data-test="formatted-tooltip-value" data-value={value}>
                      {value === 0 ? '0 units' : `${String(value)} units`}
                    </span>
                  )}
                />
              }
            />
            <ChartLegend content={<ChartLegendContent />} />
            <Bar
              dataKey="published"
              fill="var(--color-published)"
              radius={4}
              isAnimationActive={false}
            />
            <Bar
              dataKey="draft"
              fill="var(--color-draft)"
              radius={4}
              hide={!draftVisible}
              isAnimationActive={false}
            />
          </BarChart>
        </ChartContainer>
      </div>
    </ChartFrame>
  )
}
