Record rendered pair checks rather than treating these arithmetic observations as complete accessibility proof.

Choose intended foreground/fill pairs by measured AA contrast, without treating every palette swatch as a text color.

The legacy wrapper retains explicit caller precedence and its current width unless browser evidence shows a corresponding default change is required; check both layers separately. Tooltips remain portaled and support keyboard/Escape in modals and sticky headers. Table body cells wrap ordinary long content; consumers can retain nowrap explicitly. Tabs span the available track; an explicit caller width remains the opt-out. Heading components own typography without baked outer margins; Prose retains document rhythm.
