### Concrete default decisions

Palette mapping uses the retained Blue/Berry rungs (with Berry80 corrected), Orange100 as its base and80/60/40/20 as published shades4/3/2/1. Cyan/Apple/Gold100 select the approved shade4;80 selects shade5 and60/40/20 select shades3/2/1. House families keep their current values under df names; legacy aliases resolve to the same values. This uses published swatches without inventing intermediate fades.

The tinted status recipe uses Apple5/Apple1 and Cyan5/Cyan1 for text/fill; keep the Phase1 Berry error text on Orange1. Gold5 on Gold1 measures3.885:1 and cannot serve ordinary text, so warning retains its contrast-safe dark foreground. This is a measured contrast exception to the shade5 recipe; preserve the public Gold swatch itself. The existing warning accent may follow the approved Gold100 selection. Record rendered pair checks rather than treating these arithmetic observations as complete accessibility proof.

Follow the settled alignment values and published swatches. Interaction states derive through selected theme primary tokens, including the complete supported consumer ramp; UZH Blue is only the UZH default. Choose intended foreground/fill pairs by measured AA contrast, without treating every palette swatch as a text color.

Tooltip primitives use readable small text and a 20rem maximum constrained to the viewport. The legacy wrapper retains explicit caller precedence and its current width unless browser evidence shows a corresponding default change is required; check both layers separately. Tooltips remain portaled and support keyboard/Escape in modals and sticky headers. Table body cells wrap ordinary long content; consumers can retain nowrap explicitly. Tabs span the available track; an explicit caller width remains the opt-out. Heading components own typography without baked outer margins; Prose retains document rhythm. These are routine choices within the approved default-change scope, to verify in the execution fixture.
