### Binding behavior
- DateTimePicker: link an optional caller id or generated instance id to its visible label and trigger; give hour/minute/second/period controls configurable accessible names with useful defaults and instance-unique ids. Preserve forwarded trigger ref and selectors. Native text changes including paste must update the correct Date segment while preserving other date fields; maintain existing valid ranges and 12/24-hour conversion. Permit ordinary editing/navigation and modifier shortcuts. Preserve intentional segment arrow navigation/increment only when not already consumed. Native edits retain raw text until blur. One or two decimal digits update the Date immediately using existing clamping (hours 0–23, 12-hour 1–12, other segments 0–59). Empty, malformed or longer text changes no Date; blur restores the current normalized value. Valid text normalizes on blur. Native selection, deletion and paste replace the old timer-driven digit handling; left/right traverse segments only at collapsed caret boundaries. External value changes while open reset draft text and synchronize AM/PM display and subsequent edits. Do not broaden date parsing or add whole-timestamp paste.
- TextField: only actionable icons become type=button controls, with optional action/reset accessible-label props and sensible fallbacks. Decorative icons stay decorative. Buttons retain styling hooks, respect disabled, support Enter/Space, and never submit the surrounding form. Existing callbacks retain their signature.
- SelectField: derive ariaInvalid from error truthiness independently of whether error prose is hidden, consistent with peer field contracts; preserve existing consumer props precedence.
- Modal: install navigation only while open; handle only unmodified, unconsumed left/right arrows originating inside the active modal content; ignore editable controls and nested interactive widgets/popovers. Background or closed modals do not navigate. Keep escape/close and focus behavior unchanged.
